# Respawn Roguelike

A 2D roguelike game where **mathematics and geometry** lie at the heart of gameplay.

## Core Pillars
- **Geometric Combat & Movement**: Vectors, trajectories, ricochets, angles of reflection, and coordinate transformations.
- **Dynamic Physics Systems**: Gravity wells, projectile kinematics, momentum, and elasticity.
- **Procedural Mechanics**: Mathematical patterns and roguelike procedural systems.

## Agent Skills & Tooling

### `reverse-engineer-anything` (REA)
The workspace is equipped with the [REA Skill](https://github.com/morluto/rea) located under [`.agents/skills/reverse-engineer-anything/`](.agents/skills/reverse-engineer-anything/).

This skill enables Antigravity and compatible agents to analyze, deconstruct, and reverse-engineer features, mechanics, mathematical equations, and physics implementations from target apps, WebAssembly builds, JavaScript packages, and native binaries.
